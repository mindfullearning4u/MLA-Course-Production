# Moodle Course Builder

# Part 1 — Core Instructional Pages

---

# Purpose

This section defines the required construction standards for every core instructional page within an MLA Moodle lesson.

These pages form the instructional foundation of every lesson.

Regardless of subject, every lesson begins with these instructional components before students proceed to guided instruction, practice, checkpoints, or assessments.

The Course Architecture and Planning Agent determines:

- whether a page is required,
- the instructional purpose,
- the lesson sequence,
- the Moodle activity type,
- the required resources,
- the required evidence.

The Moodle Course Builder Agent constructs the page exactly as specified.

No instructional decisions should be made during construction.

---

# Standard Construction Rule

Every page built inside Moodle must contain:

1. Purpose
2. Moodle Activity Type
3. Placement
4. Required Components
5. Student Directions
6. Student Focus
7. Required Evidence
8. Visual Requirements
9. Accessibility Requirements
10. Moodle Configuration
11. Definition of Done

No page type is exempt.

---

# Lesson Overview Page

## Purpose

The Lesson Overview prepares students for the lesson.

Students should immediately understand:

• what they will learn

• why the lesson matters

• what work they will complete

• what evidence they must submit

• how the lesson connects to previous learning

• how the lesson prepares them for future lessons

This page is the student's roadmap.

---

## Moodle Activity Type

Page

Do not build as:

Assignment

Quiz

Book

Forum

URL

---

## Placement

Always the first page of every lesson.

Nothing instructional appears before this page.

---

## Required Header

Every Lesson Overview begins with:

Course Name

Unit Number

Lesson Number

Lesson Title

MLA Lesson ID

Example

BIOLOGY

Unit 1

Lesson 2

Scientific Investigation

BIO-U1-L2

The header must match the approved MLA format.

---

## Lesson Focus

One concise paragraph.

Explain:

What students will learn.

Why it is important.

How it connects to previous lessons.

How it prepares them for later lessons.

Avoid generic wording.

---

## Learning Objectives

Objectives must be measurable.

Use verbs such as:

Explain

Analyze

Interpret

Compare

Calculate

Construct

Evaluate

Design

Identify

Differentiate

Avoid

Understand

Know

Learn about

Become familiar with

Objectives should describe observable performance.

---

## Standards

Display only the primary MLA standards.

Do not display large tables of Florida or Common Core codes.

Those belong in the Crosswalk.

Students only need the instructional focus.

---

## Evidence Checklist

Students should immediately know:

What work must be retained.

What work must be submitted.

Separate evidence into categories.

Example

Vocabulary

Notebook Task 1

Notebook Task 2

Lesson Review

Independent Application

Checkpoint Evidence

Investigation

Data Table

Written Analysis

Assessment

Lesson Quiz

Students should know every required product before beginning the lesson.

---

## Student Expectations

State clearly:

Complete every required page.

Complete activities in sequence.

Return to Moodle after Savvas.

Maintain your notebook.

Submit required evidence.

Review Teacher of Record feedback.

Students should understand expectations before beginning.

# Moodle Course Builder

# Part 2 — Guided Instruction

---

# Purpose

This section defines the standards for building guided instructional pages within an MLA lesson.

Guided instruction occurs after students understand the lesson objectives and before they are expected to demonstrate independent mastery.

These pages provide structured learning experiences that teach concepts, model thinking, demonstrate procedures, and prepare students for independent practice.

The Moodle Course Builder Agent must construct every guided instructional page exactly as defined in the approved Unit and Lesson Map.

Never invent instructional activities.

Never omit approved instructional activities.

Never substitute another activity type because it appears easier to build.

---

# Guided Instruction Philosophy

Guided instruction teaches.

Independent activities assess.

Students should receive sufficient instruction before they are expected to demonstrate mastery.

Every guided instructional page should answer:

• What concept am I learning?

• Why is this concept important?

• How do I perform this skill correctly?

• What should I notice?

• How will I use this later?

---

---

## Student Directions

Directions must specify:

What students should complete.

How many items they should complete.

Whether calculators may be used.

Whether complete sentences are required.

Whether work must be shown.

Whether notebook responses are required.

Never state:

Instead state:

Complete Problems 1–6.

Show every calculation.

Circle the final answer.

Record all work in your notebook.

Connections to the checkpoint.

Continue to Independent Application.

Continue to Notebook Task.

Continue to Lesson Review.

---

# Guided Instruction Quality Checklist

Every guided instructional page must include:

✓ Clear purpose

✓ Student-friendly directions

✓ Student focus

✓ Required evidence

✓ Notebook reminders when applicable

✓ Transition to next activity

✓ Visual consistency

✓ Accessibility

✓ Correct Moodle activity type

✓ Clear completion expectation

Students should complete guided instruction without requiring verbal clarification from the Teacher of Record.
